# Apache-Hive-Assignment

A Big Data project using **Apache Hadoop, HDFS, Apache Hive, HiveQL, and Docker** to analyze retail transaction data.

## Tech Stack

- Apache Hadoop & HDFS
- Apache Hive
- HiveQL
- Docker & Docker Compose
- Beeline
- CSV

## Workflow

```text
CSV → HDFS → Hive External Table → Data Cleaning → HiveQL Analysis
```

## Features
- Store transaction data in HDFS
- Create an external Hive table
- Clean missing values
- Calculate total sales revenue
- Calculate average order value by category
